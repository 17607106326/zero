## 🧩 功能模块详解

> 20 个模块全部本地存储、按需启用（设置 → 功能模块）。以下为各模块的核心能力：

### 🏠 今日 · 生活仪表盘
- 可拖拽、可缩放的 widget 网格（6 列，卡片可跨 1~6 列、1~3 行）。
- 内置 16 个 widget：问候、待办统计、今日心情、本月支出、正在阅读、时钟、今日习惯、最近日记、近期支出、快捷操作、迷你日历、天气、快速启动、今日头条、那年今日、本周周报。
- 支持「自定义布局」拖动排序、调宽调高、隐藏卡片；布局按生活 / 工作两种模式分别保存。

### 🗺️ 旅行
- 新建行程（标题 / 目的地 / 出发返程日期 / 预算），三态：计划中 / 进行中 / 已完成。
- 行程内加景点（分类、时长、门票、Wiki 链接，按天拖拽分配）与行前准备（预订 / 必带 / 同行人）。
- 预算进度实时估算并可一键「记一笔」联动记账；行程可导出 PDF，带坐标景点绘制离线地图点位图。

### 📋 待办
- 自定义分类侧栏，多视图：今天 / 时间线 / 明天 / 本周 / 全部 / 已完成。
- 单条支持优先级、截止日期 + 提前提醒、重复（每天 / 每周 / 每月）、子任务拆解。
- 今日总览含完成环、逾期列表、近 7 天趋势；每条可一键开始 25 分钟专注番茄钟；删除有 5 秒撤销。

### 📅 日历
- 月历聚合纪念日 / 生日、待办、课程三类圆点；自动获取法定节假日（在线获取并降级内置数据）。
- 可加纪念日 / 生日，每年重复，自动算「第 N 周年 / N 岁」；当日详情聚合节假日、事件、待办与课程。

### ⏰ 定时
- 健康定时任务：5 个预设（喝水 / 护眼 / 起身 / 上厕所 / 吃药）一键添加，可自定义间隔（15 分~8 小时）、活跃时段、星期。
- 闹钟：精确到分、可备注、按星期重复或每天 / 工作日。

### 🎯 规划
- 年度目标与心愿清单两个页签；目标按年份切换，可拆里程碑（截止日期、完成勾选、逾期高亮，进度按比例计算）。
- 目标主题色轮换；删除带撤销。

### 🎓 课程表
- 学期设置：开学日期（自动算周次）、总周数、每日节数、每周天数（1~7）。
- 课程支持周次模式（每周 / 单周 / 双周 / 指定周次）；单门课含名称、教师、地点、跨节次、颜色、备注；空格子点击快速建课。

### 📖 日记
- 左侧搜索、7 种心情筛选、标签筛选与统计；编辑器含标题、心情、天气 / 位置、标签、正文。
- 列表按日期分组，删除入 30 天回收站；顶部「心情」页签内嵌完整心情模块。

### 💰 记账
- 三张汇总卡：本月收入 / 支出 / 净额（含储蓄率），对比上月涨跌。
- 交易支持 10 类支出、5 类收入；按分类月度预算（超 80% 警告、超支报警）。
- 统计图表：本月支出分类饼图 + 近 6 个月收支柱状图（ECharts）。

### 📚 读书
- 统计正在阅读 / 今年读完 / 全部 / 年度目标进度（默认 24 本）。
- 想读 / 在读 / 已读 / 暂停四状态页签；卡片含封面、进度条、1~5 星评分；详情可记书评与精彩摘录。

### 🧠 知识库
- 搜索、分类、标签筛选；笔记支持 Markdown 编辑 / 预览（渲染经净化）。
- 支持置顶、网格 / 列表双视图；删除入 30 天回收站。

### 📝 便签
- 两种位置：内置悬浮（覆盖所有页面）与桌面独立小窗（常驻桌面）。
- 内置便签可拖动、改大小、自动保存；多颜色随主题换肤；一键发到桌面 / 收回 / 删除。

### ✅ 习惯
- 新增可设图标、颜色、频率（每天 / 每周）、每周目标次数、提醒时间。
- 卡片显示连续天数 🔥、本周进度；每周概览矩阵（习惯 × 7 天）；详情含当前 / 最长连续与近 30 天完成率。

### 🖼️ 相册
- 时间线（按月分组）与相册（自建相册含封面）两种视图。
- 多选上传落原图 + 缩略图，尝试从 EXIF 回填拍摄日期；单张灯箱可编辑、删除（入回收站）；沉浸影院全屏播放。

### 🚀 快捷操作
- 管理项目 / 文件夹 / 程序 / 连接（网页）四类条目。
- 瀑布流（增删改分组、拖拽排序）与分块（只读、同类合并）双布局；最近启动 Top5 与使用次数统计；支持 JSON 导入 / 导出。

### 🧰 工具
- 共 33 个工具，分 6 组：编码转换、文本处理、单位 / 进制、开发辅助、生活常用、安全隐私。
- 覆盖十六进制解码、Base64、JSON、哈希、UUID、正则、Cron、JWT、SQL、房贷、税后工资、复利、BMI、农历、密码生成、信息脱敏等；左侧分组导航 + 搜索。

### 🔐 密码库
- 主密码机制（首次 ≥6 位，密钥仅留内存）；按空闲分钟数自动锁定。
- 记录含标题、用户名、密码、网址、标签、备注，可搜索与标签筛选。
- 复制密码不进剪贴板历史，可设复制后自动清空；内置密码生成器（8~64 位）。

### 📋 剪贴板
- 全局快捷键呼出快速面板，复制文本约 1 秒内入库；列表按置顶 / 今天 / 昨天 / 更早分组。
- 敏感内容过滤（跳过私钥 / Token / 密码）；快速面板自动粘贴；容量上限 100~2000 条。

### 📷 截图
- 全局快捷键选区截图 + 长截图；截后可自动复制、进标注编辑器（画笔 / 箭头 / 文字 / 马赛克 / 步骤序号）。
- 网格浏览（懒加载），可钉在桌面、复制、删除、加备注搜索；大图预览可缩放（20%~800%）平移。

### 🐟 摸鱼
- 6 款小游戏：贪吃蛇、俄罗斯方块、2048、扫雷、打砖块、记忆翻牌。
- 内联懒加载，支持键盘 + 屏幕按钮；音效 / 背景音开关与音量控制（背景音仅游戏时播放）。
