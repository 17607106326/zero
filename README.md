## ✨ 特性

- 🔒 **完全本地**：不注册、不登录、不依赖官方服务器，数据存进你自己的电脑
- 🪶 **极致轻量**：安装包仅 3 MB，体积小、无负担、下载即用
- 🧩 **20 个功能模块**：今日 / 旅行 / 待办 / 日历 / 定时 / 规划 / 课程表 / 日记 / 记账 / 读书 / 知识库 / 便签 / 习惯 / 相册 / 快捷操作 / 工具 / 密码库 / 剪贴板 / 截图 / 摸鱼，按需勾选、拖拽排序
- 🎨 **3 套主题 + 自定义主题**：白天、夜间、液态玻璃……支持跟随系统与昼夜/天气/季节联动
- 🌗 **生活 / 工作双模式**：各自记忆模块集合与主题，一键切换互不打扰
- 📝 **便签双形态**：应用内悬浮 + 独立桌面小窗，五色跟随主题气质换肤，双向实时同步
- 🌱 **会长大的桌宠**：完成待办、打卡习惯攒经验进化，还会定时冒泡陪你
- 🎯 **专注胶囊**：15 / 25 / 45 分钟番茄钟，支持暂停与继续

## 📝 更新日志

Zero 在持续迭代中不断优化，这里记录每一次值得关注的更新。最新安装包见上方「下载」。

### 2026-09-19
- **主题精简**：内置主题由 10 套精简为 3 套（白天 / 夜间 / 液态玻璃）；昼夜、天气、季节/节日等动态联动模式保留并重新映射。

- **更新方式说明**：版本更新界面新增「自动检查 / 手动覆盖安装」二选一说明，明确本程序没有内置更新服务器、更新地址需自行填写。

### 2026-09-18
- **工具箱模块**：新增「工具」模块与首个工具（十六进制解码），可在设置中按需启用，后续持续扩充。
- **主页小组件布局重排**：默认改为「零空洞」网格布局，支持拖拽排序、显隐与尺寸调整。

### 2026-09-14
- **快捷操作模块重写**：支持分组管理与双布局（瀑布流 / 分块），涵盖程序、连接、项目、文件夹四类快捷入口。

### 2026-09-12
- **副屏全屏模式**：可将主窗口移动到副屏并以全屏方式运行，自动避让其他窗口，方便大屏专注场景。
